# Java Бариста

Інтерактивні уроки з Java у стилі Duolingo. Працює в браузері на комп'ютері й телефоні, без встановлення та реєстрації.

**Відкрити:** https://mariiaosadchaa.github.io/EspressoCode/

## Як це працює

Кожен урок складається з трьох частин:

1. **Вивчаємо.** Короткі картки з поясненням, прикладом коду та результатом його виконання.
2. **Тренуємось.** Завдання чотирьох типів: тести, заповни пропуск у коді, склади код із рядків, що виведе код. Помилка коштує одне життя з п'яти.
3. **Повторюємо.** Режим «Повторення» змішує завдання з пройдених уроків і першими ставить ті, де були помилки.

За правильні відповіді нараховується досвід, а за щоденні заняття росте серія днів.

## Що в курсі

9 розділів, 18 уроків, 128 завдань:

| Розділ | Теми |
| --- | --- |
| Перші кроки | структура програми, вивід, коментарі |
| Змінні й типи | змінні, типи даних |
| Оператори | арифметика, порівняння, логіка |
| Умови | if / else, switch |
| Цикли | for, while |
| Масиви та методи | масиви, методи |
| Класи та об'єкти | класи, конструктори, інкапсуляція |
| Колекції | ArrayList, HashMap |
| Винятки | try / catch / finally, throw |

Усі приклади коду з уроків перевірено запуском у Java 21.

## Запуск локально

Це один файл без залежностей. Відкрийте `index.html` у браузері.

Прогрес зберігається в `localStorage` браузера, тому на іншому пристрої він почнеться заново.

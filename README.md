# Java Бариста

Інтерактивні уроки з Java у стилі Duolingo. Працює в браузері на комп'ютері й телефоні, без встановлення та реєстрації.

**Відкрити:** https://mariiaosadchaa.github.io/EspressoCode/

## Як це працює

Кожен урок складається з трьох частин:

1. **Вивчаємо.** Короткі картки з поясненням, прикладом коду та результатом його виконання.
2. **Тренуємось.** Шість типів завдань: тест, заповни пропуск, склади код із рядків, що виведе код, знайди помилку, впиши код сам. Помилка коштує життя, а підказка допоможе, якщо застряг.
3. **Повторюємо.** Режим «Повторення» змішує завдання з пройдених уроків, першими ставить ті, де були помилки, і нагадує про уроки, які давно не відкривались.

## Можливості

- Тест рівня: можна пропустити розділи, які вже знаєш.
- Три рівні складності: легкий (7 життів), звичайний (5), складний (3 життя, без підказок, нагорода ×1,5).
- Шість типів завдань, підказки, розбір помилки: що саме ти відповів і як правильно.
- Повторення за інтервалами: застосунок сам планує, коли показати завдання знову. Режим «Слабкі місця» тренує розділи, де найбільше помилок.
- Прогрес: графік досвіду за тиждень, точність за розділами, час навчання, 15 досягнень.
- Шпаргалки з усіх розділів, їх можна роздрукувати. Озвучення карток теорії.
- Пісочниця: пишеш Java і запускаєш код прямо в застосунку (через публічний сервіс Judge0).
- Лисичка-бариста з гардеробом: капелюхи, окуляри й шарфи відкриваються з рівнями. Кожен розділ починається з маленької історії.
- Денна ціль, серія днів із «заморозкою», подвійний досвід на вихідних, звуки, світла й темна теми, великий шрифт і спокійний режим.
- Нагадування: файл календаря з щоденною подією.
- Акаунт і хмарне збереження прогресу (Supabase), синхронізація між пристроями.
- Працює офлайн і встановлюється як застосунок (PWA).

## Запуск локально

Відкрийте `index.html` у браузері. Для встановлення як застосунку потрібен https (GitHub Pages).

Прогрес зберігається в `localStorage` браузера. Щоб перенести його на інший пристрій, скопіюйте резервний код у «Налаштуваннях».

## Акаунти й база даних (Supabase + Vercel)

Без налаштування застосунок працює як раніше: прогрес лежить у браузері. Щоб увімкнути входи й хмарне збереження:

1. Створи проєкт на [supabase.com](https://supabase.com). У SQL Editor виконай вміст `supabase.sql`.
2. У Supabase: Authentication → Sign In / Providers → Email. Для простоти вимкни «Confirm email» (або залиш увімкненим, тоді вхід буде після підтвердження пошти).
3. У Project Settings → API скопіюй Project URL і anon public key у `config.js`.
4. На [vercel.com](https://vercel.com): Add New → Project → імпортуй цей репозиторій → Deploy. Налаштування збірки не потрібні.
5. Після деплою додай адресу сайту в Supabase: Authentication → URL Configuration → Site URL.
